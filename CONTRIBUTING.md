# Contributing / المساهمة

Thanks for improving Screenshot Manager. Keep changes focused and preserve the local-first, preview-before-mutation design.

1. Use .NET 8 SDK.
2. Create a focused branch.
3. Add or update tests for behavior changes.
4. Run `dotnet build -c Release` and `dotnet test tests/ScreenshotManager.Tests/ScreenshotManager.Tests.csproj -c Release`.
5. Do not add telemetry, secrets, destructive defaults, generated build output, or unrelated dependencies.
6. Open a pull request describing user-visible behavior and validation performed.

## العربية

نرحب بالمساهمات المحددة والواضحة. حافظ على عمل المشروع محليًا وعلى مبدأ المعاينة قبل أي تعديل للملفات. أضف اختبارات للسلوك الجديد، وشغّل البناء والاختبارات قبل الإرسال، ولا تضف أسرارًا أو تتبعًا أو حذفًا افتراضيًا أو ملفات بناء مولدة.
